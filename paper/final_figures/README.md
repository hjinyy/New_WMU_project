# Final paper figures

This folder contains the finalized main-paper WMU figure set. Exactly nine figures are included. No new Simulink simulation, raw waveform generation, feature extraction, ML training, greedy placement, robustness evaluation, or metric recomputation was performed while preparing this folder. The files were selected from existing validated figure outputs and, where necessary, visually composited without changing source data or result values.

## Contents

- `png/`: publication-ready PNG files.
- `pdf/`: publication-ready PDF files.
- `captions/`: English captions for Figures 1–9.
- `source_index.csv`: source provenance for every final figure.
- `figure_index.md`: paper-section mapping, purpose, and file links.

- Figure 1: Overall methodology — Methodology
- Figure 2: IEEE14 and IEEE30 test systems — System and Dataset
- Figure 3: Representative event waveform signatures — Waveform Characteristics

- Figure 8: Fault-parameter robustness — Robustness
