## Separation of failures
- `No Valid Fault Window` is an extraction abstention; no Stage-2 result is inferred.
- A valid window with `Ambiguous`/wrong candidate is a public-proxy localization outcome, not a window failure.
- `BLOCKED_REFERENCE_BUS_MODEL` remains an evaluation-only denominator rule; Bus 1 is never fabricated as a zero-response candidate.
- Clearing contamination uses manifest timing only after extraction, for audit; it is never an extraction input.
